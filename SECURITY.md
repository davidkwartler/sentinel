# Security policy

Sentinel is a session hijack detection demo, deployed at
[sentinel.davidkwartler.com](https://sentinel.davidkwartler.com).

## Reporting a vulnerability

Email [david@davidkwartler.com](mailto:david@davidkwartler.com), the same
contact as [davidkwartler.com/.well-known/security.txt](https://www.davidkwartler.com/.well-known/security.txt).
Please don't open a public issue for a security report.

Only the current `main` branch, as deployed, is supported.
